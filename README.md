# Sales & Inventory Analytics Dashboard

**Power BI | Data Analysis | Procurement | Inventory Management**

An interactive Power BI dashboard designed to analyze sales performance, product and brand performance, vendor activity, and inventory levels.
The dashboard is built using a relational data model combining sales, purchasing, product, vendor, store and inventory data. DAX measures were created to support KPI calculations and business analysis.

## Dashboard Pages

### Sales Overview
- Sales performance and trends
- Sales quantity and transactions
- Sales by brand, store and classification

### Product Analysis
- Product and brand performance
- Sales and profitability analysis
- Average sales price

### Vendor Analysis
- Supplier performance
- Purchase value and quantity
- Gross profit and average purchase price

### Inventory Analysis
- Stock levels
- Inventory value
- Inventory distribution by brand and store

## Key KPIs

- Total Sales
- Total Quantity
- Average Sales Price
- Sales Transactions
- Gross Profit
- Total Purchase
- Total Vendors
- Average Purchase Price
- Ending Inventory
- Beginning Inventory
- Average Inventory
- Inventory Value

## Tools

- Power BI
- DAX
- Data Modeling
- Data Visualization
- Business Analysis
- Procurement & Inventory Analysis
